# 🚴 RideTrace

**Every ride leaves a trace. — 내가 달린 길과 높이를 다시 보다.**

2025년 대한민국 자전거 국토종주 경험에서 시작한 GPX 기반 라이딩 기록 시각화 프로젝트입니다.

## 사용하기

1. [RideTrace 실행](https://metasongi.github.io/ride-trace/) 페이지를 엽니다.
2. 내 GPX 파일을 선택합니다. 파일은 브라우저에서 처리되며 서버로 업로드하지 않습니다.
3. 2D 지도를 확인하거나 3D로 전환하여 고도를 살펴봅니다.
4. **지도 회전**과 **카메라 회전**을 별도로 조절합니다.
5. 고도 배율과 애니메이션 재생을 이용해 경로를 다시 확인합니다.

## 주요 기능

- GPX 트랙/루트 업로드 및 다중 파일 선택
- 2D 지도, 3D 고도 경로
- 방위각(지도 회전)과 카메라 높이/시점 회전 분리
- 고도 배율, 고도 프로필, 경로 애니메이션
- 모바일 화면 지원

## 기술

HTML5 · CSS · Vanilla JavaScript · Canvas · GPX(XML) · GPS 좌표

## 현재 제한

실제 산악 지형을 재현하는 서비스는 아닙니다. GPX의 `ele` 값이 있는 경우 해당 경로의 높낮이를 표시합니다. 고도가 없는 GPX는 평면 경로만 확인할 수 있습니다.

## 개인정보

**실제 주행 GPX에는 집 주소나 개인 이동 경로가 포함될 수 있습니다.** 공개 저장소에 실제 GPX 원본을 무심코 업로드하지 마세요. `data/demo.gpx`는 합성 예제입니다.
